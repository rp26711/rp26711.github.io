Unit Summaries

Unit 1 – Introduction to Big Data Technologies and Data Management

Learning Objectives

This unit provided an introduction to the key features, technologies, and concepts underpinning Big Data. It explored the exponential growth of data through an evaluation of the 4/5 Vs of Big Data, considering both the advantages and risks associated with increasingly complex datasets and technologies. The unit also introduced the critical analysis of Big Data methodologies and technologies, alongside an examination of data security requirements and Big Data management systems.

Reading Summaries

Huxley (2020) explored the importance of data cleaning and quality checking of datasets to ensure reliable analysis. The study discussed approaches to handling duplicates, missing values, extreme values, and inaccurate data. It also highlighted the importance of researchers documenting their data-cleaning processes to provide transparency and an accurate representation of the data used in the analysis. This reading reinforced the importance of data quality as a fundamental stage of the data science process, particularly because poor-quality data can directly affect the reliability and validity of subsequent analysis. However, the perspective focused primarily on researchers' handling of data, rather than considering data cleaning and quality management within a real-world Big Data context.

Balaji, Sonowal and Gowda (2024, Chapter 8, Sections 8.1–8.28) discussed the concept of Big Data through consideration of the five Vs: volume, velocity, variety, value and veracity. The reading identified key dimensions of Big Data, including real-time data, shared data, linked data and high-fidelity data. It also explored technologies associated with Big Data, including machine learning, cloud computing, fog computing and edge computing, alongside real-world applications such as smart homes, healthcare and smart cities. This reading provided a strong introduction to Big Data, its associated technologies and applications, and demonstrated how these technologies are increasingly being integrated into everyday life. However, while the reading identified ways in which Big Data can support cybersecurity, further consideration of the potential negative impacts and security risks associated with Big Data would provide a more balanced perspective.

McKinney (2022, Chapter 1) introduced how Python can be used to manipulate, process, clean and analyse data, exploring how data can be structured differently and the implications this has for data analysis. The chapter also focused on Python's suitability for a range of data-related functions, before introducing essential Python libraries and tools, including NumPy, pandas, Matplotlib, IPython and Jupyter. It also provided guidance on accessing and using Python. This reading provided a useful introduction to how Python can be applied to data analysis and demonstrated how accessible Python can be as a tool for beginning to work with data. However, as an introductory chapter, it provided limited discussion of the more advanced applications and potential limitations of Python within data science.

Activity Summaries

Lecturecast - The Lecturecast this week introduced me to big data, looking at how it is defined and what is meant by the Four V’s of Big Data. It covered methodologies and techniques used in handling big data, such as data cleansing, normalisation, and standardisation. It also explored tools used to handle big data, such as SQL and Python, as well as strategies including data modelling and machine learning. The Lecturecast then provided an overview of data types before exploring structured, semi-structured, quasi-structured, and unstructured data in more detail. It also covered common data formats such as CSV, JSON, and XML. Finally, it briefly introduced human-readable data formats and parsing data into a clean and logical format.

Introductory seminar - The introductory seminar introduced the Four V’s of Big Data: volume, variety, velocity, and veracity, which describe the size, different formats, speed, and complexity of big data. It also explored how the perception of data has changed from being viewed as raw material used to generate information to being inherently valuable and useful for building understanding and making decisions. The material discussed how the complexity of data depends on how it is structured and introduced technologies used to manage and analyse large amounts of data, including data mining, data exploration, data analysis, and data presentation. It also covered methodologies, tools, techniques, and strategies for handling data, including cleansing, standardisation, formatting, and normalisation, as well as the use of APIs, tools, and filters to reduce errors and noise within datasets. Finally, it highlighted the importance of data modelling for understanding relationships between data, reducing redundancies, and considering data security requirements when handling data.

Collaborative - discussion forum - This Unit was also the first week of Collaborative Discussion 1, during which I completed further reading to develop an initial post on the topic of the data collection process and the Internet of Things (IoT). My submission for this initial post can be found here.

Key Lessons Learned

Reflecting on the key lessons learned this week, I developed a greater understanding of the complexity and scale of big data, particularly in relation to the four/five Vs. I also explored how big data can exist in different formats and considered the additional complexities this creates when attempting to manage, process, and analyse such data. Furthermore, I developed a broader understanding of the different methods that can be used to analyse big data and the considerations involved in selecting appropriate approaches. Through developing my initial post for the discussion forum, I was able to apply this learning to the context of the Internet of Things (IoT) and develop my own critical perspective on the challenges associated with big data. In particular, I explored issues relating to data quality and data security, considering the potential implications of these challenges and the importance of addressing them effectively. This process helped me to recognise that the value of big data is not solely dependent on the volume of data collected, but also on the quality, security, and reliability of that data. Consequently, this week has strengthened my understanding of the need to critically evaluate how big data is collected, managed, and analysed, particularly within increasingly connected IoT environments.
