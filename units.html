My PGCert ePortfolio Unit Summaries

Unit Summaries

Unit 1 – Introduction to Big Data Technologies and Data Management This week developed my understanding of Big Data through the five Vs: volume, velocity, variety, value and veracity (Balaji, Sonowal and Gowda, 2024). I recognised that its value depends not only on scale, but also on data quality, reliability and security. Huxley (2020) demonstrated how inadequate data cleaning, including unresolved missing, duplicate or inaccurate data, can undermine analytical validity. McKinney (2022) introduced Python as a practical tool for data manipulation, cleaning and analysis. Applying these concepts to IoT highlighted the complexity of continuously generated, diverse datasets. Overall, I developed a more critical understanding of how effective data management enables reliable insights while addressing quality and security challenges.

Unit 2 – Introduction to Data Types and Formats This week developed my understanding of how data types and formats influence the storage, processing and analysis of Big Data. Balaji, Sonowal and Gowda (2024) demonstrated how technologies such as Hadoop, MapReduce, Hive and NoSQL address the limitations of traditional data-processing approaches. McKinney (2022) further developed my practical understanding of Python data structures, file handling and data parsing, including the use of pandas to access data from files, databases and APIs. Critically, I recognised that structured, semi-structured, quasi-structured and unstructured data present different challenges for interoperability, processing and management. Applying these concepts through Python and peer discussion strengthened my ability to evaluate appropriate tools and techniques for data wrangling, particularly within complex IoT environments.

Unit 3 – Data Collection and Storage This week developed my understanding of different data sources and the importance of data quality, integrity and reliability. McKinney (2022) demonstrated how Python and pandas can support data cleaning through handling missing values, removing duplicates and transforming data. Sardar and Pandey (2024) highlighted the challenges of managing large IoT datasets and the importance of scalable cloud solutions, filtering and appropriate data storage. I also gained practical experience of web scraping using Python, Requests and BeautifulSoup to collect and structure online data. Overall, I developed a stronger understanding of how effective data management, fact-checking and data cleansing can support reliable analysis and decision-making.

Unit 4 – Data Cleaning and Transformation

Learning Objectives

This unit provided an introduction to the key concepts, techniques, and methods underpinning data cleaning and transformation. It explored the data management pipeline, examining the factors that affect data cleaning and the requirements critical to effective data design and process automation. The unit also developed an understanding of how to clean and transform data using the data pipeline as a guide, alongside evaluating the requirements for designing automated data processes.

Activity Summaries

Data Management Pipeline Test covered key Python concepts, libraries, and best practices used for effective data management and programming. The test included membership testing with in and not in, the Zen of Python, CSV writing, string formatting, dictionary values, list generators/comprehensions, and datetime methods such as strftime() and strptime(). It also focused on good Python practices, including following PEP 8, using clear naming and proper syntax, importing only what is needed, testing code, using version control and existing libraries, creating reusable helper functions, handling exceptions appropriately, documenting code with comments and README.md files, organizing repositories logically, and prioritizing clear, readable code when using Python's syntactic sugar.

Unit 5 – Data Cleaning and Automating Data Collections

Learning Objectives

The unit also introduced database representation and architecture, with a focus on understanding inputs and outputs, selecting appropriate automation tools, and using data models to represent relationships between data.

Unit 6 – Database Design and Normalisation

Learning Objectives

This unit provided an introduction to database design and normalisation, exploring the construction of relational databases and the organisation of data for effective storage and retrieval. It examined the role of key fields and data cleaning methods in maintaining usable datasets, alongside analysing anomalies and their impact on database integrity. The unit also explored logical and physical database design, including the requirements and limitations of physical architecture, and developed an understanding of the principles and different normal forms used in database normalisation.

Unit 7 – Constructing Normalised Tables and Database Build

Learning Objectives

This unit developed practical skills in database normalisation by transforming an un-normalised table through 1NF, 2NF, and 3NF, demonstrating the stages involved in creating a structured relational database. It examined data attributes, associations, operations, relationships, and functional dependencies, alongside identifying constraints and limitations associated with datasets. The unit also explored the construction and testing of relational database models to ensure usability, accuracy, and the identification of potential errors or anomalies.

Unit 9 – Database Management Systems (DBMS) and Models

Learning Objectives

This unit explored the key concepts and theories underpinning Database Management Systems (DBMS), examining a range of database technologies including flat files, relational and non-relational databases, object-oriented systems, data warehouses, cloud-based platforms, Hadoop, HDF, and data lakes. It evaluated the strengths, limitations, and application environments of different DBMS approaches, alongside considering their relevance to different programming paradigms. The unit also developed an understanding of how to evaluate database design choices and apply appropriate solutions when designing applications that manage large datasets.

Unit 11 – DBMS Transaction and Recovery

Learning Objectives

This unit explored transaction processing and the mechanisms used to maintain database reliability, consistency, and data integrity when system failures occur. It examined the ACID properties of transactions and their role in ensuring that database operations are completed correctly, while also considering scheduled transactions, system failures, checkpoints, and the transaction cycle. The unit further developed an understanding of transaction managers and how they coordinate fast-moving and interleaved transactions to maintain a consistent database state.
