Project scenario

Initially, a suitable scenario for the project was identified through research into areas where AI-assisted database analytics could provide practical benefits. The project focuses on running gear and performance, reflecting the growing popularity of running and the challenges associated with the selection of appropriate running gear. For this project, I position myself as a software and database consultant working for a fictional fitness and running retail organisation. The client is interested in investigating whether the type of running gear purchased by customers is associated with differences in their running performance. The organisation requires a more structured approach to managing sales and fitness performance data to improve the recommendation of personalised products to their customers, as information relating to customers’ purchases and running performance is difficult to analyse collectively. The proposed solution is a logical relational database capable of storing, cleansing, managing and analysing customer, product, sales, training and race performance data. The resulting analytical data will be presented through an interactive dashboard to provide the client with meaningful insights into product usage and any associations with running performance. The project will investigate how AI tools can support the database development and analytics pipeline, including schema design, data cleansing, SQL development, feature extraction and insight generation, while maintaining appropriate human validation, data-quality controls and critical oversight.
