Project Title

AI-Assisted Running Retail Database Analytics and Performance Dashboard

Project scenario and client


Initially, a suitable scenario for the project was identified through research into areas where AI-assisted database analytics could provide practical benefits. The project focuses on running gear and performance, reflecting the growing popularity of running and the challenges associated with the selection of appropriate running gear.

For this project, I position myself as a software and database consultant working for a fictional fitness and running retail organisation. The client is interested in investigating whether the type of running gear purchased by customers is associated with differences in their running performance.

The organisation requires a more structured approach to managing sales and fitness performance data to improve the recommendation of personalised products to their customers, as information relating to customers’ purchases and running performance is difficult to analyse collectively.

The proposed solution is a logical relational database capable of storing, cleansing, managing and analysing customer, product, sales, training and race performance data. The resulting analytical data will be presented through an interactive dashboard to provide the client with meaningful insights into product usage and any associations with running performance.

The project will investigate how AI tools can support the database development and analytics pipeline, including schema design, data cleansing, SQL development, feature extraction and insight generation, while maintaining appropriate human validation, data-quality controls and critical oversight.

Project Aim

To design and develop an AI-assisted relational database and analytics solution that enables a fictional running retail organisation to integrate sales and running performance data and generate meaningful business and performance insights that support personalised product recommendations to customers.

Project Objectives

The broad objectives of this project are as follows:

  • Identify the client's data and information requirements.
  • Investigate the quality and structure of the available running and retail data.
  • Design a logical relational database integrating customer, product, sales and performance data.
  • Investigate how AI can support database schema design and data cleansing.
  • Develop a data-cleaning and transformation process using Python/Pandas.
  • Implement the proposed relational database.
  • Develop SQL queries to answer relevant business and performance questions.
  • Extract useful analytical features from the dataset.
  • Develop an interactive dashboard.
  • Critically evaluate the effectiveness and limitations of AI within the database analytics pipeline.

    • Project Research Questions

    The key project questions that will guide the development and analysis within this project are as follows:

  • PQ1: What entities, attributes and relationships are required to integrate running gear and customer purchase data with running training and race performance data?
  • PQ2: What data-quality problems exist within the dataset, and how can AI assist in identifying and resolving them?
  • PQ3: How does race performance vary between customers using different running product categories?
  • PQ4: Are there observable differences in race performance when customers use specific running products?
  • PQ5: How accurate and useful are AI-generated database and analytical outputs when compared with human-validated results?

    • Client Requirements

    What does the client require?

    The client requires a system that can identify associations between running gear and running performance. The system should combine customer, training, race and product data to identify patterns that can be used to provide personalised gear recommendations.
    To support meaningful performance analysis, the system should also distinguish between products purchased by customers and products used during training or races. This will allow the organisation to investigate whether particular products or product categories are associated with differences in running performance, rather than assuming that a purchased product was necessarily used during a particular activity or race.

    Why does the client need this?

    The client needs these insights to improve the quality and personalisation of product recommendations provided to customers. Recommendations can be incorporated into personalised customer support, allowing recommendations to be based on customer characteristics, training and running performance rather than relying on generic product suggestions.

    What decisions should the database support?

    The database should support decisions relating to:

  • Personalised product recommendations based on customer characteristics, training and running performance
  • Product selection, by identifying which types of running gear are associated with differences in performance
  • Customer segmentation, by identifying different customer profiles and their equipment and training needs
  • Sales strategies, by helping staff identify appropriate products for different customers
  • Customer support, by providing evidence-based information that can be used to explain recommendations and improve customer trust
