Unit Summaries

Unit 1 – Introduction to Big Data Technologies and Data Management
This week developed my understanding of Big Data through the five Vs: volume, velocity, variety, value and veracity (Balaji, Sonowal and Gowda, 2024). I recognised that its value depends not only on scale, but also on data quality, reliability and security. Huxley (2020) demonstrated how inadequate data cleaning, including unresolved missing, duplicate or inaccurate data, can undermine analytical validity. McKinney (2022) introduced Python as a practical tool for data manipulation, cleaning and analysis. Applying these concepts to IoT highlighted the complexity of continuously generated, diverse datasets. Overall, I developed a more critical understanding of how effective data management enables reliable insights while addressing quality and security challenges.
Unit 2 – Introduction to Data Types and Formats
This week developed my understanding of how data types and formats influence the storage, processing and analysis of Big Data. Balaji, Sonowal and Gowda (2024) demonstrated how technologies such as Hadoop, MapReduce, Hive and NoSQL address the limitations of traditional data-processing approaches. McKinney (2022) further developed my practical understanding of Python data structures, file handling and data parsing, including the use of pandas to access data from files, databases and APIs. Critically, I recognised that structured, semi-structured, quasi-structured and unstructured data present different challenges for interoperability, processing and management. Applying these concepts through Python and peer discussion strengthened my ability to evaluate appropriate tools and techniques for data wrangling, particularly within complex IoT environments.
Unit 3 – Data Collection and Storage

Learning Objectives

This unit provided an introduction to the different sources of data and explored methods for verifying data integrity, considering the implications that data quality and reliability can have on businesses and data analysis. It examined approaches to fact-finding and source verification, alongside different methods of data collection and their practical applications. The unit also developed a deeper understanding of the memory and storage requirements associated with different data formats. In addition, it evaluated web services and crowdsourced data, and explored the methods, applications, and use cases of web scraping for collecting and analysing data from online sources.

Activity Summaries

Lecturecast - The Lecturecast this week explored data sources and data management, looking at how data can be collected from a variety of online and offline sources, including primary and secondary sources. It covered the importance of data verification and fact-finding to ensure data quality, as well as factors such as readability, cleanliness, longevity, and appropriate data storage. It also introduced cloud storage and how data can be accessed remotely across different platforms. The Lecturecast then explored web services and APIs, focusing on how they enable communication between different processes, devices, and systems. It also examined crowdsourced data, including its applications, advantages, and challenges such as quality control, selection bias, data overload, and API reliability. Finally, it introduced web scraping, including how Python libraries can be used to collect data from websites, the basic layout of HTML websites, and the legal and ethical considerations associated with web scraping.

Web Scraping Activity - To test and expand my knowledge of web scraping, I developed a web scraping script in Python using the BeautifulSoup and Requests libraries. The script takes a URL and a keyword, uses Requests to send an HTTP request to the webpage, and then processes the webpage using BeautifulSoup. It searches for the keyword, returns the extracted data and number of results, and stores the data in JSON format. Developing this script helped me put into practice the learning from previous units, particularly understanding how programs work, the benefits of web scraping, and how different tools and data-wrangling techniques can be applied in real-world contexts. It also helped me develop a better understanding of how programming can be used to collect and structure data efficiently.

Collaborative discussion forum – This unit hosted the final week of Collaborative Discussion 1, during which I developed a summary post based on my initial post, feedback from my peers, and the content of Units 1, 2, and 3. This process allowed me to reflect on my initial thoughts, engage with feedback, and undertake further reading to support and develop my ideas. My submission, along with a further evaluation of my peer-review contributions, can be found here.

Data Management Pipeline Test covered key Python concepts, libraries, and best practices used for effective data management and programming. Unit 7 – Constructing Normalised Tables and Database Build

Learning Objectives

This unit developed practical skills in database normalisation by transforming an un-normalised table through 1NF, 2NF, and 3NF, demonstrating the stages involved in creating a structured relational database. It examined data attributes, associations, operations, relationships, and functional dependencies, alongside identifying constraints and limitations associated with datasets. The unit also explored the construction and testing of relational database models to ensure usability, accuracy, and the identification of potential errors or anomalies.

Unit 9 – Database Management Systems (DBMS) and Models

Learning Objectives

This unit explored the key concepts and theories underpinning Database Management Systems (DBMS), examining a range of database technologies including flat files, relational and non-relational databases, object-oriented systems, data warehouses, cloud-based platforms, Hadoop, HDF, and data lakes. The unit also developed an understanding of how to evaluate database design choices and apply appropriate solutions when designing applications that manage large datasets.

Unit 11 – DBMS Transaction and Recovery

Learning Objectives

This unit explored transaction processing and the mechanisms used to maintain database reliability, consistency, and data integrity when system failures occur. It examined the ACID properties of transactions and their role in ensuring that database operations are completed correctly, while also considering scheduled transactions, system failures, checkpoints, and the transaction cycle. The unit further developed an understanding of transaction managers and how they coordinate fast-moving and interleaved transactions to maintain a consistent database state.
