Data Cleaning Activity



In weeks 4–5, I learned how structured data cleaning improves data quality and consistency. Following Kazil and Jarmul’s (2016) UNICEF Zimbabwe survey example, I practised file conversion and variable labelling. Huxley (2020) taught me how fuzzy matching can identify inconsistencies, alongside checking missing values, duplicates, and formatting errors. Integrating these techniques into one script highlighted the importance of automation and reproducibility in producing reliable datasets for accurate analysis.

    • Normalisation Task



    In week 7, I learned how database normalisation improves data quality and efficiency by reducing redundancy and preventing update anomalies (Chen, 2023). Applying 1NF, 2NF, and 3NF taught me to identify repeating values, partial dependencies, and transitive dependencies systematically. This task highlighted how careful database design maintains data integrity and consistency. I also recognised that effective data modelling provides a more reliable and scalable foundation for managing complex datasets.
  • Normalisation Task


    • Data Building Task



    In week 7, I learned to apply normalisation principles in PostgreSQL by creating linked tables using primary and foreign keys. Testing relationships through JOIN queries and invalid data entries taught me how to verify referential integrity and identify inconsistencies. This task highlighted the importance of carefully structuring tables and selecting unique identifiers. I also learned that testing database assumptions is essential for maintaining data accuracy, consistency, and reliability.
  • Data Building Task


    • API Security Requirements



    In week 10, I evaluated security requirements using NASA Open APIs, developing my understanding of the risks involved in accessing and sharing data. Independent research into authentication, authorisation, data protection, and vulnerabilities revealed the multifaceted nature of API security. This task taught me that clearly defined security requirements are crucial for protecting sensitive data, preventing unauthorised access, and ensuring APIs remain reliable and trustworthy.
