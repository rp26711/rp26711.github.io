Other Artefacts

Web Scrapping Activity

This task deepened my understanding of web scraping as a data-wrangling process rather than simple extraction. I learnt to critically consider data quality, limitations, and ethical/security risks while using Requests and BeautifulSoup to transform unstructured web data into structured formats.

Data Cleaning Activity

The data cleaning activity helped me reflect on data cleaning as a structured and repeatable process rather than an isolated task. Working with the UNICEF dataset demonstrated how transformation, fuzzy matching and scripting can improve data quality. I also developed a clearer understanding of how defined inputs, outputs and data models support effective automation and scalable data pipelines

Data Management Pipeline Test

This test prompted me to reflect on the difference between code that works and code that is reliable and maintainable. I recognised that testing, version control, documentation and modular design are essential for developing reproducible data pipelines. It also highlighted how Python best practices improve clarity, reduce errors and support effective collaboration throughout the development process.

Normalisation Task

The normalisation task strengthened my understanding of how database structure influences data quality and efficiency. Working through 1NF, 2NF and 3NF helped me recognise and resolve redundancy and dependency issues systematically. I also reflected on how appropriate data modelling supports scalable solutions, reduces inconsistencies and provides a stronger foundation for managing complex datasets.

Data Building Task

The data build task allowed me to apply normalisation principles in a practical database environment. Creating linked tables and implementing primary and foreign keys strengthened my understanding of relational data structures and referential integrity. Testing the database also highlighted the importance of validating relationships to maintain data consistency and support reliable data processing.

API Security Requirements

The API security requirements task developed my understanding of the risks involved in sharing and accessing data through APIs. Evaluating authentication, authorisation, data protection and potential vulnerabilities helped me recognise that secure data wrangling requires security to be considered alongside functionality. Working collaboratively also reinforced the importance of assessing risks from different perspectives.

Back Up Procedure Activity

The backup procedure activity helped me reflect on how data management must account for failure and recovery, not just storage and processing. Evaluating the Grandfather-Father-Son strategy showed me how structured backup cycles can balance storage requirements, recovery needs and resource use. Comparing it with alternative approaches strengthened my ability to critically assess which method is most appropriate for different datasets and operational requirements.
